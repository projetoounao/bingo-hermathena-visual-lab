# BINGO/Hermathena Visual Lab

Repositório público de publicação do **BINGO/Hermathena Visual Lab**.

Este repositório contém apenas materiais destinados à publicação web. A documentação de trabalho, decisões, histórico e código-fonte interno permanecem no repositório privado `projetoounao/collab-hermathena-bingo-editorial`.

## Estado atual

Smoke test de infraestrutura para validar GitHub Pages antes da **Brand Review 01**.

Capacidades testadas:

- HTML/CSS/JavaScript;
- `localStorage`;
- Outfit + Inter;
- importação e exportação JSON;
- abertura/download de PDF;
- SVG;
- motion CSS;
- áudio gerado no navegador;
- impressão;
- responsividade.

> Este repositório público não representa aprovação final da identidade visual nem um Brand Kit vigente.
